## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/prashantpiyush1111/LeetCode.git
cd LeetCode
```

Open any solution in a Java-compatible IDE such as IntelliJ IDEA, Eclipse, or VS Code.

For standalone Java files, a typical command sequence is:

```bash
javac FileName.java
java FileName
```
